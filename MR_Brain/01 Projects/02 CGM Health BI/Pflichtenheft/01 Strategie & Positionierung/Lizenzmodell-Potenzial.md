# Lizenzmodell-Potenzial

Die Plattformarchitektur eröffnet Lizenzmodelle, die heute nicht möglich sind:

| Modell | Beschreibung |
| --- | --- |
| **Semantic Subscription** | Zugang zum gepflegten, aktualisierten Standardmodell |
| **Widget Marketplace** | Drittanbieter entwickeln zertifizierte Widgets (Umsatzbeteiligung) |
| **Connector-Zertifizierung** | Dritttools zahlen für Zertifizierung gegen die Semantic API |
| **AI Add-on** | NLP-Abfragen als Premium-Feature auf bestehendem Semantic Layer |

> [!info] Bezug
> Voraussetzung ist die Umstellung von Einzellizenzen auf Themen-/Bundle-Lizenzen (separater Prozess, siehe [[Scope – In & Out of Scope]]).
